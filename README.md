# 上岸指南 · AI 秋招求职路线

面向 AI 全栈开发 / AI 创造者学生的秋招求职工作台：选一个岗位方向，生成这条路的五步路线——投哪些公司、刷哪些面试题、刷哪些算法题、四周怎么排、看哪些资料。

- 3823 家企业开发研发岗（12 个岗位方向，可筛选可搜索）
- 171 道面试题（含考点 / 答法 / 追问 / 相关资料四层）
- 50 道 LeetCode + 18 道手撕题（每题配题解 + 同类题专题）

每道题都挂了「相关知识文档」外链，共 148 篇（MDN、官方文档、原论文、JavaGuide、代码随想录、Google SRE、OWASP、LearnOpenGL 等），学生觉得答法不够深，可以直接点开原文往下挖。

## 说明

- 页面纯静态，不需要后端；勾选进度存在浏览器本地（换设备不同步）。
- `jobs.js` 是岗位数据，必须和 `index.html` 同层，缺了岗位库会空。
- `.nojekyll` 用来关掉 GitHub 的 Jekyll 处理，别删。
- 岗位数据来自校招内推表，投递前以企业官网实时状态为准。
